# 需求说明

| 字段 | 内容 |
| --- | --- |
| 目标 | 调整组织用量报表的人数、趋势和组织名称展示，并同步 XLSX |
| 背景 | 当前人数标题不符合业务称呼，趋势缺少总 Token，组织显示内部域名 |
| 用户 / 受众 | 管理端组织用量报表使用者 |
| 提出人 | 用户 |
| 日期 | 2026-08-09 |

## 成功标准

| ID | 标准 | 需要的证据 |
| --- | --- | --- |
| SC-1 | 用量概览将 `active_users` 标为“注册人数”，将 `used_users` 标为“活跃人数” | 组件测试与页面检查 |
| SC-2 | 组织汇总采用同一人数标题 | 组件测试与页面检查 |
| SC-3 | 用量趋势显示总 Token，不显示缓存 Token 曲线 | Chart 数据集测试 |
| SC-4 | 页面所有组织展示点把迅游和速宝内部键显示为指定中文名称 | 筛选器、汇总、人员表测试 |
| SC-5 | XLSX 同步人数标题和组织显示名 | 工作簿单元测试 |
| SC-6 | API、筛选值、后端分组和统计语义不变 | 请求断言、源码 diff 与类型检查 |

## 范围

| 本次范围 | 不在本次范围 |
| --- | --- |
| Vue 组织用量组件展示 | 后端接口、仓储、SQL 或数据库变更 |
| 中英文界面的人数标题和品牌显示名 | 修改 `active_users` / `used_users` 的计算语义 |
| 趋势数据集从缓存读取替换为总 Token | 删除 API 或导出中的缓存 Token 字段 |
| XLSX 人数标题与组织名称 | 调整趋势 `as_of`、粒度、补零和请求状态机 |
| 必需测试、组件 README、feature 设计与 wiki 同步 | 无关页面重构或视觉改版 |

## 约束

| 类型 | 约束 |
| --- | --- |
| 技术 | 使用现有 Vue 3、TypeScript、vue-i18n、Chart.js 与 Vitest 模式 |
| 产品 | 页面和 XLSX 同步；精确显示“迅游”“速宝” |
| 安全 / 数据 | 组织内部键与请求参数不可改变，避免影响后端分组 |
| 分支 / 发布 | 分支为 `feature/hy/10174_org_usage_report_display`；未经后续授权不推送或合并 |

## 假设

| ID | 假设 | 为什么安全 |
| --- | --- | --- |
