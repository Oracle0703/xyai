## 上游原生问题

以下问题可在 `MERGE_HEAD` 原始文件中复现，不是本地冲突解决引入。用户已明确要求等待远端修复，因此本分支只记录、不修改对应生产实现。

| 级别 | 问题 | 上游证据 | 影响 |
| --- | --- | --- | --- |
| P1 | 异步图片结果 URL 由默认 HTTP client 下载，没有私网/metadata/DNS rebinding/redirect 防护。 | `backend/internal/service/image_storage.go` | 不可信或失陷的自定义上游可诱导服务端访问内网。 |
| P2 | async image 任务由进程内 goroutine 执行，无持久 worker/recovery。 | `backend/internal/handler/image_task_handler.go`; `service/image_task.go` | 服务重启后 `processing` 任务可能悬挂到默认 24h TTL。 |
| P2 | 批量限额 cache 删除底层吞掉 Redis 错误，全量 user ID 展开查询存在 PostgreSQL bind 参数上限。 | `api_key_auth_cache_impl.go`; `api_key_repo.go`; `admin_user.go` | DB 已更新但认证快照可能短期残留；大用户量全量操作的 cache 查询可能失败。 |
| P2 | 新增 locale message compile 测试直接导入 `@intlify/message-compiler`，但 `frontend/package.json` 未声明该直接依赖。 | `frontend/src/i18n/__tests__/localesMessageCompile.spec.ts`; `frontend/package.json` | pnpm 严格依赖链接下该 suite 无法收集，完整 Vitest 返回非零。 |
