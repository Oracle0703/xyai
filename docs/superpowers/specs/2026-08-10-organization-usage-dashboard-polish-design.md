# 组织用量运营看板小范围补强设计

## 目标

在不修改后端、API、趋势逻辑、人员表和 XLSX 结构的前提下，修复导出与筛选状态不一致，并补齐运营概览最关键的信息解释。

## 设计

1. 页面维护当前筛选草稿与最后已应用筛选的稳定指纹。只有两者一致时允许导出；查询、重置和组织汇总行筛选均同步该指纹。
2. 概览使用现有字段展示六项 KPI：注册人数、活跃人数、活跃率、请求数、总 Token、实际成本。
3. `range.as_of` 在概览日期旁显示为报表级数据截止时间。
4. 注册人数、活跃人数、总 Token 使用现有 `HelpTooltip` 解释口径。
5. Champion 使用现有组织名称 formatter 显示迅游、速宝或其他。

## 非目标

- 不增加趋势线、成本趋势或组织多线对比。
- 不增加零用量人员筛选、时间对比、预算或预警。
- 不修改数据库、后端、API、DTO、人员表或工作簿结构。

## 验证

按 TDD 增加 View、Filters、Overview 和 locale 用例；最后运行组织用量专项测试、typecheck、lint:check 与 `git diff --check`。
