01
INSTALL THE EXTENSION

安装 VS Code 官方扩展

先安装或更新 VS Code，再安装由 Anthropic 发布的 Claude Code for VS Code。

Claude Code for VS Code发布者：Anthropic · 官方扩展anthropic.claude-code
前往官方扩展页面 下载 VS Code
  1. 1.打开 VS Code，按 Ctrl + Shift + X 进入扩展。
  2. 2.搜索 Claude Code for VS Code，核对发布者 Anthropic 后安装。
  3. 3.打开 VS Code「设置」，搜索 @ext:anthropic.claude-code，按下方说明设置。

关闭 Use Terminal：使用扩展图形面板，保持 claudeCode.useTerminal 为 false。

开启 Disable Login Prompt：使用中转站配置，勾选 claudeCode.disableLoginPrompt。

注意：还需勾选 bypass 权限设置

在 VS Code「设置」中搜索 bypass，找到并勾选 Claude Code: Allow Dangerously Skip Permissions，如下图红框所示。

此项允许使用 Bypass permissions（跳过权限确认）模式，是 VS Code 扩展中需要手动开启的独立设置。

需要 VS Code 1.94.0 或更高版本。扩展自带运行组件，无需另行安装命令行客户端。

04
READY IN VS CODE

回到 VS Code，开始使用

看到配置写入成功后，重新打开 VS Code 和本地项目，进入 Claude Code 扩展面板。

在扩展图形面板中发起对话
  1. 重新打开 VS Code，选择本地项目文件夹。
  2. 按 Ctrl + Shift + P，搜索 Claude Code，选择 Open in New Tab 或 Open in Side Bar。
  3. 在 Claude Code 面板中新建对话，选择账号可用的 Claude 模型，发送下方测试消息。
请用一句话介绍你能如何帮助我完成当前项目。

扩展面板收到回复，并且中转站出现对应使用记录，才算完成接入。

后续使用始终在 VS Code 的 Claude Code for VS Code 面板中进行。
仍然出现登录提示，怎么办？

检查 VS Code 设置中的 Disable Login Prompt 已勾选，再完全退出并重新打开 VS Code。核对脚本显示的目录与扩展使用的 CLAUDE_CONFIG_DIR 是否一致；中转站 Key 不用于登录 Claude 官网。

为什么打开的是终端界面？

请关闭 VS Code 扩展设置中的 Use Terminal，然后通过命令面板选择 Claude Code: Open in New Tab 或 Open in Side Bar。本中转站仅允许扩展图形面板使用，不允许终端会话。

没有回复或提示 Key / 模型不可用？

在中转站确认 Key 有效、额度足够、所属分组支持所选 Claude 模型。重新运行配置脚本可更新 Key。Windows 请在系统 PowerShell 中配置本机用户目录；本指南针对本机 VS Code，不适用于 WSL、SSH 或容器里的扩展。

macOS 配置后如何生效？

脚本会写入 ~/.claude/settings.json，并同步终端启动配置。完成后完全退出 VS Code，再重新打开；如果曾设置 CLAUDE_CONFIG_DIR，请确保脚本和扩展使用同一绝对路径。
